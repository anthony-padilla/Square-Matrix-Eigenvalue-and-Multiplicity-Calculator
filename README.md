# Square Matrix Eigenvalue and Multiplicity Calculator #
## Overview ##

This program computes the geometric and algebraic multiplicites for square matrices, implemented in C++. Consider the matrix:
- [  3, 1, 0, 1 ]
- [ -1, 5, 4, 1 ]
- [  0, 0, 2, 0 ]
- [  0, 0, 0, 4 ]

The correct output of the program should be:
- 4,4,2 ( from the minimal polynomial )
- 4,4,4,2 (from the characteristic polynomial)

Where the eigenvalues of the matrix are 4,2.
